# Plugin add
- Status bar button
- Desktop widget

# Button have a LMB and RMB functions
- LMB: mode list
- RMB: settings
- In settings enable "modes - Open Near Clicked Widget" and "settings - Open Near Clicked Widget"

# Functions
- You can create modes
- Add application for has start in mode or closing
- Application in mode has automatic closing if you switch mode
- Set workspace and display for application on start
